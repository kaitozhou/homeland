# 建邺区 3D 房产地图设计 Spec

事业部：未识别，使用默认 service-retail 全局样式作为视觉基线  
配色来源：地图数据工具自定义深色蓝绿底 + 服务零售强调橙用于筛选选中态  
设计基准：桌面优先，兼容 375px 移动宽度

## 编码约束

- 页面首屏直接展示地图工具，不做营销落地页。
- 控件稳定尺寸，筛选变化不引发布局跳动。
- 信息字段合并排布，避免一字段一行。
- 样式外置到 CSS，颜色、圆角、阴影使用 CSS 变量。
- 地图 key 只从环境变量读取，缺失时给出可感知错误。

## 全局视觉基线

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#eef3f7` | 页面背景 |
| `--color-panel` | `#ffffff` | 面板与卡片 |
| `--color-text` | `#101820` | 主文字 |
| `--color-muted` | `#667085` | 辅助文字 |
| `--color-accent` | `#ff6b35` | 筛选选中、住宅强调 |
| `--color-map` | `#0f2233` | 地图兜底底色 |
| `--radius-card` | `8px` | 面板/卡片圆角 |
| `--shadow-panel` | `0 18px 48px rgba(15, 34, 51, 0.16)` | 悬浮面板阴影 |

## 页面布局策略

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部摘要栏：标题 / 数据更新时间 / 关键指标                    │
├───────────────┬──────────────────────────────────────────────┤
│ 左侧筛选面板   │ 高德 3D 地图                                 │
│ 板块筛选       │ 板块 polygon 高亮                             │
│ 住宅形态筛选   │ 住宅/商业/医院/公园不同 marker                 │
│ 价格/年代筛选  │ hover 住宅显示详情卡                           │
├───────────────┴──────────────────────────────────────────────┤
│ 数据来源与质量提示                                            │
└──────────────────────────────────────────────────────────────┘
```

## 模块视觉细节

| 模块 | 结构 | 关键参数 |
| --- | --- | --- |
| 顶部摘要 | 左标题右指标 | 高 72px，白底，1px 分隔线，指标横排 |
| 筛选面板 | VStack 分组 | 宽 340px，内边距 18px，gap 18px，移动端转顶部抽屉式块 |
| 筛选按钮 | wrap chips | 高 32px，圆角 8px，选中背景 `#fff3e8`，边框 `#ffb48f` |
| 地图容器 | FullWidth | 填满剩余空间，最小高 620px，圆角 8px |
| hover 卡 | Overlay | 右上角定位，宽 320px，白底阴影，字段两列组合 |
| 质量报告 | 横向提示条 | 字号 12px，浅橙背景，链接样式按钮 |

## 决策摘要

- 地图供应商为高德 JS API 2.0，不做 Mapbox 分支。
- 板块底层按建邺区 6 个街道组织，同时保留房产板块标签。
- 入图住宅只保留字段齐全的小区；缺失数据进入质量报告。
