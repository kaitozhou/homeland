## 复核口径

- `price_hidden_transaction`：公开网页能看到成交记录、面积和时间，但总价/单价隐藏或打码，需要人工补价。
- `newhouse_reference_price`：公开网页为新房参考单价/总价，不是二手成交价。
- `web_reference_price`：公开网页为小区参考价、价格走势或榜单价，不是单套成交价。
- `*_name_review`：项目名、分期名或页面城市路径存在不一致，已写入但必须人工复核后才能作为最终成交口径。

## 后续建议

1. 优先用能直接展示总价和单价的成交详情页替换 `price_hidden_transaction` 与 `web_reference_price` 记录。
2. 对 `*_name_review` 记录优先核对项目分期、区位和建筑年代，避免同名或近似楼盘误归并。
3. 每次回填后运行 `npm run data:validate`、`npm run xhs:status`、`npm run build`，确认数据结构、统计和页面构建同步。
